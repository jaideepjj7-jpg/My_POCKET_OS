03 / The main project

Meet Pocket OS.

A browser-based, operating-system-inspired project made for fun, curiosity, and learning. It is my way of exploring the ideas that make a desktop environment feel like a system.

▣

A mini desktop experience

Pocket OS is built primarily with vanilla HTML, CSS, and JavaScript — without relying on a large front-end framework for its core interface. The goal is to experiment with familiar desktop-style interactions inside a web page.

Depending on the features implemented, a project like this can include a desktop layout, app-like panels, menus, windows, settings, and small utilities. Each feature is an opportunity to learn how interface state and interactions fit together.

Vanilla JavaScriptHTMLCSSUI experiments
Why I started

Curiosity over perfection.

I started Pocket OS for fun because I wanted to understand what goes into making an operating system and a desktop-like environment. I wanted to explore the moving parts, the design decisions, and the logic behind interactive software.

Quick clarification: Pocket OS is a learning project that runs in a browser; it is not a replacement for a real operating system or a claim to implement a full OS kernel. The project is about exploring OS-inspired ideas through web development.
